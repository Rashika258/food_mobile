# 📱 FoodApp Mobile App (React Native & Expo)

Cross-platform iOS and Android mobile app for the Multi-sided Food Delivery Platform (Commercial Restaurants + Hyper-Local Home Makers < 5 KM).

## Highlights
- **Neighborhood GPS Detection**: Auto-detects customer location and loads home makers within a 5 KM radius.
- **Dual Mode**: Switch between Instant Commercial Restaurants and Homestyle Kitchens.
- **Portion Countdown Badges**: Visual indicator of daily batches left.
- **Shared API**: Consumes the same backend REST API (`http://localhost:5000/api/v1`).

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start Expo dev server
npx expo start
```
